## Installation & Usage

### Installation

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```

### Running the Application

-   **Development Mode**:
    ```bash
    npm run start
    ```
-   **Watch Mode**:
    ```bash
    npm run start:dev
    ```
-   **Production Mode**:
    ```bash
    npm run start:prod
    ```

### Running Tests

-   **Unit Tests**:
    ```bash
    npm run test
    ```
-   **End-to-End (E2E) Tests**:
    ```bash
    npm run test:e2e
    ```
-   **Test Coverage**:
    ```bash
    npm run test:cov
    ```
